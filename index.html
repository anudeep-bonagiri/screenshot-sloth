Screenshot Sloth

Your screenshots get real names while you do nothing.

Runs on this device. Nothing is uploaded.

1. The model

Gemma 4 E2B, Google's open-weight model, runs on your GPU in this tab and looks at each screenshot itself. It is about a 3.4 GB download the first time, then it loads from this browser's storage.

Needs Chrome or Edge on a laptop or desktop (WebGPU).

2. The folder

On a Mac screenshots land on the Desktop unless you changed it. On Windows they are in Pictures/Screenshots. The browser will ask once for permission to edit that folder.

Screenshots

Names are suggestions until you press Rename. Click a name to edit it. Every rename is written to screenshot-sloth-log.csv in the folder.

How this works

  1. The browser opens your folder. Chrome's File System Access API lets this page read and rename files in the one folder you pick, after you allow it. Nothing is copied anywhere.
  2. Gemma looks at each screenshot. Gemma 4 E2B runs on your GPU through WebGPU and Transformers.js. It answers with a short title, a type and whether the image shows a secret.
  3. Code does the rest. The date comes from the old file name. The name is cleaned for every file system, collisions get a number, and the file moves into its folder. The model never touches a file.
Tries to send a request to an outside server from this page and from the model's worker. The browser should refuse both.

The Private folder is a convenience, not a security tool. In testing on made-up screenshots, the careful setting caught 8 of 15 that showed a password, code, key, card or ID. The other setting caught 15 of 15 but also sent 11 of 27 ordinary screenshots to Private. Do not count on either to find your secrets.
